🌐 Portfólio | Miguel Amores

Este repositório contém o código-fonte do meu portfólio pessoal, desenvolvido com HTML, CSS e JavaScript, com foco em um layout moderno, responsivo e com modo claro/escuro.

O objetivo do projeto é apresentar meus projetos, habilidades técnicas, formação e formas de contato, servindo como vitrine profissional.

✨ Visão Geral

O portfólio conta com:

Página única (SPA) com navegação por âncoras

Design responsivo (desktop e mobile)

Alternância entre modo claro e escuro

Seções bem definidas para projetos, sobre mim e contato

Integração com redes sociais e GitHub
